## PRICING MODEL

**Free.** All tools are free to use, no account required, no paywall, no freemium tier.

## TIERS

| Tier | Price | Features |
|------|-------|----------|
| Free (only tier) | €0 | All tools, all features, export, no limits |

There are no paid tiers. This is not a commercial product.

## REVENUE STRATEGY (optional, not MVP)

- **Donation link** — Optional "Support the project" button (Buy Me a Coffee, PayPal)
- **Portfolio value** — The tools serve as a live demonstration of Domenico's skills
- **No ads** — Ads would compromise the creative experience and require ad network accounts

## COST TO USER

| Resource | Cost | Notes |
|----------|------|-------|
| Money | €0 | Completely free |
| Data | None | No tracking, no data collection (consistent with DOME's existing privacy stance) |
| Browser resources | CPU/RAM | Audio analysis and canvas rendering use resources; ffmpeg.wasm (P3) is heavy |
| Install | None | Browser-based, no download needed |

## WHY FREE

1. DOME is a portfolio site — tools demonstrate skill, not generate revenue
2. GitHub Pages is free — no hosting cost to recover
3. Firebase Spark tier is free — no backend cost for MVP
4. Open source ethos — tools are built on open Web APIs, should remain open
