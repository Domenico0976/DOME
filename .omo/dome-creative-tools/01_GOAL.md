## CORE OBJECTIVE

Build a collection of free, browser-based creative tools — covering image manipulation, video editing, text generation, and audio-reactive visual components — that live inside the existing DOME website hosted on GitHub Pages, requiring no backend server and zero hosting cost.

## WHY THIS PROJECT EXISTS

Domenico wants to create a creative tool suite inspired by sites like tools.sketchdesign.club, offering audio-reactive components, image/video/text tools accessible directly in the browser. The DOME site already exists on GitHub Pages with a working Firebase integration and deploy workflow. The goal is to extend DOME with a React-based tools section without adding hosting costs or backend complexity.

## SCOPE BOUNDARIES

**In scope:**
- Browser-based tools using Web Audio API, Canvas/WebGL, File API
- React + Vite app embedded in the DOME repo
- GitHub Pages deployment with Firebase secret injection
- Progressive tool addition (start with audio-reactive, expand later)

**Out of scope (for MVP):**
- Server-side video encoding or rendering
- User accounts or paid tiers (Firebase Auth is optional, not required for MVP)
- Mobile-native apps
- Real-time collaboration features

## NORTH STAR

A user visits dome-fusto.pages.dev/tools, picks a tool, loads a file or enables the mic, and gets a creative output — all in the browser, no install, no signup, no cost.
