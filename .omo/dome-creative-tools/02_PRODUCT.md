## PRODUCT OVERVIEW

DOME Creative Tools is a browser-based creative tool suite embedded in the existing DOME portfolio site. Users access it at `/tools` and interact with a grid of available tools. Each tool is a self-contained React component that uses Web APIs (Audio, Canvas, File) to process user input and produce creative output — all client-side, no server.

## KEY FEATURES (MVP)

1. **Audio-Reactive Visualizer** — User loads an audio file or enables the mic. The tool analyzes frequency data via Web Audio API AnalyserNode and renders reactive visuals on a Canvas/WebGL surface. Sensitivity control, multiple visual modes (waveform, particles, bars).

2. **Image Tool** — User uploads an image. Tool applies effects (filters, glitch, pixel sort, color shift) via Canvas API. Export as PNG.

3. **Tool Registry** — A central registry that maps tool slugs to components, metadata (name, description, icon, category), and lazy-loads them on demand.

## KEY FEATURES (P2/P3 — not MVP)

4. **Text Tool** — Generative text effects, ASCII art, typographic animations
5. **Video Tool** — Frame extraction, basic editing via ffmpeg.wasm
6. **Tool Presets** — Save/load configurations via Firebase Realtime Database
7. **Gallery** — Community showcase of outputs

## USER FLOW

```
Visit dome-fusto.pages.dev/tools
  → See tool grid (available tools as cards)
  → Click a tool
  → Tool loads (lazy, code-split)
  → User interacts (upload file / enable mic / adjust controls)
  → Real-time visual output on canvas
  → Export button (download result)
```

## TECHNICAL SURFACE

- **Frontend**: React 18 + Vite, embedded in DOME repo at `/tools-app/`
- **Build**: GitHub Actions workflow, Vite build with `VITE_FIREBASE_*` env vars
- **Deploy**: GitHub Pages, artifact from `tools-app/dist/`
- **Audio**: Web Audio API (AudioContext, AnalyserNode, getByteFrequencyData)
- **Graphics**: Canvas 2D API (MVP), optional WebGL/Three.js for advanced modes
- **State**: React state + optional Firebase Realtime Database for presets
- **Routing**: HashRouter (required for GitHub Pages subpath)

## WHAT IT IS NOT

- Not a SaaS product — no paid features, no user dashboard
- Not a backend service — all processing client-side
- Not a replacement for professional tools (After Effects, Photoshop) — a creative playground
