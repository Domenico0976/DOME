## P1 — DO NOW (highest leverage, unblocks everything else)

1. **Scaffold React + Vite app in `DOME/tools-app/`**
   - `npm create vite@latest tools-app -- --template react`
   - Configure `vite.config.js` with `base: '/tools/'` for GitHub Pages subpath
   - Install `react-router-dom`, use `HashRouter` for routing
   - Verify: `npm run dev` works locally

2. **Adapt the GitHub Actions deploy workflow**
   - Add Node setup, npm ci, npm run build steps to existing `deploy.yml`
   - Pass `VITE_FIREBASE_*` env vars to the build step
   - Upload artifact from `tools-app/dist/` instead of root
   - Verify: workflow runs green on push to master

3. **Build the first tool: Audio-Reactive Visualizer**
   - Create `useAudioAnalyser` hook (AudioContext + AnalyserNode)
   - Create `AudioVisualizer` component (Canvas 2D, frequency bars + waveform)
   - Add file upload + mic enable toggle
   - Add sensitivity slider control
   - Verify: tool works live on dome-fusto.pages.dev/tools

## P2 — DO NEXT (after P1 is live and verified)

2. **Video Tool** — ffmpeg.wasm frame extraction

## ANTI-PATTERNS TO AVOID

- Do NOT build all tools before deploying — ship P1 first
- Do NOT add Firebase Auth until a feature actually needs it
- Do NOT use BrowserRouter — it breaks on GitHub Pages refresh
- Do NOT assume audio works without a user gesture (browser autoplay policy)
- Do NOT bundle ffmpeg.wasm in the initial build — it's 30MB+, add only for video tool
