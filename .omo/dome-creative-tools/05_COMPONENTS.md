## COMPONENT ARCHITECTURE

```
tools-app/
├── vite.config.js          # base: '/tools/', env exposure, code splitting
├── package.json
├── index.html              # Vite entry
├── src/
│   ├── main.jsx            # React root, HashRouter
│   ├── App.jsx             # Layout + route definitions
│   ├── components/
│   │   ├── ToolGrid.jsx     # Landing page — tool cards from registry
│   │   ├── ToolShell.jsx    # Wrapper: title, controls, canvas, export
│   │   └── ui/
│   │       ├── Slider.jsx   # Reusable control
│   │       ├── FileDrop.jsx # Reusable file upload
│   │       └── Button.jsx   # Reusable button
│   ├── hooks/
│   │   ├── useAudioAnalyser.js  # Web Audio API wrapper
│   │   ├── useCanvasRenderer.js # Canvas 2D abstraction
│   │   └── useFileUpload.js     # File handling
│   ├── tools/
│   │   ├── AudioVisualizer.jsx  # MVP tool 1
│   │   ├── ImageTool.jsx        # P2 tool
│   │   └── TextTool.jsx         # P3 tool
│   ├── lib/
│   │   ├── registry.js      # Tool registry (slug → component + metadata)
│   │   ├── firebase.js      # Firebase init from VITE_FIREBASE_*
│   │   └── export.js        # Canvas → PNG download utility
│   └── styles/
│       └── tools.css        # Tool-specific styles
└── dist/                    # Build output (uploaded to Pages)
```

## REUSABLE COMPONENTS (shared across >50% of tools)

| Component | Used by | Reuse Strategy |
|-----------|---------|----------------|
| ToolShell | All tools | Standard layout: header, controls panel, canvas area, export button |
| FileDrop | Audio, Image, Video tools | Drag-drop + click upload, type validation, object URL |
| Slider | Audio, Image, Text tools | Range input with label, value display, callback |
| useCanvasRenderer | Audio, Image, Text tools | Canvas context, resize handling, animation loop |
| export.js | All tools with visual output | Canvas.toBlob → download link |

## TOOL-SPECIFIC COMPONENTS (not shared)

| Component | Tool | Purpose |
|-----------|------|---------|
| useAudioAnalyser | Audio Visualizer | AudioContext, AnalyserNode, frequency data |
| AudioVisualizer | Audio Visualizer | Renders frequency data to canvas |
| ImageProcessor | Image Tool | Canvas filter pipeline, glitch algorithm |
| TextGenerator | Text Tool | Typography effects, ASCII conversion |

## BUILD PIPELINE

```
push to master
  → GitHub Actions triggered
  → checkout code
  → setup Node 20
  → npm ci (in tools-app/)
  → npm run build (with VITE_FIREBASE_* env vars)
  → Vite outputs to tools-app/dist/
  → upload-pages-artifact from dist/
  → deploy-pages serves it at /tools
```

## DEPENDENCY GRAPH

```
registry.js
  → React.lazy(() => import tools/AudioVisualizer)
  → React.lazy(() => import tools/ImageTool)

AudioVisualizer
  → useAudioAnalyser (Web Audio API)
  → useCanvasRenderer (Canvas 2D)
  → ToolShell (layout)
  → FileDrop (audio file upload)
  → export.js (PNG/screenshot)

ImageTool
  → useCanvasRenderer
  → ToolShell
  → FileDrop (image upload)
  → export.js
```
