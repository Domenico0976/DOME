## DECISION BOUNDARIES

- **Domenico decides**: tool priority, architecture, UI/UX, what to ship
- **GitHub Actions executes**: build, secret injection, deploy — no decisions, just execution
- **Firebase serves**: data storage only when explicitly called by client code
- **AI Assistant suggests**: code patterns, fixes, optimizations — never deploys or merges

## AUTONOMY LIMITS

No agent in this system has autonomous deployment rights. All code changes go through Domenico's local dev → push to master → Actions builds → Pages deploys. There is no auto-merge, no AI-driven CI/CD.
