## FAILURE MODE MAP

| Failure | Trigger | Probability | Impact | Contained By |
|---------|---------|-------------|--------|--------------|
| AudioContext blocked | Page load without user gesture | High | Critical — tool doesn't work | 08_LIMITS: create AudioContext only after click |
| AudioContext suspended | Tab backgrounded, browser policy | Medium | High — visuals freeze | Resume on visibilitychange event |
| Pages artifact > 1GB | ffmpeg.wasm bundled in main chunk | Medium (P3) | Critical — deploy fails | 08_LIMITS: dynamic import for wasm |
| Vite base path wrong | Missing `base: '/tools/'` in config | Medium | Critical — assets 404 | Verify in build output, test before deploy |
| Firebase env vars empty | Secrets not injected in Actions | Medium | High — Firebase init fails | 08_LIMITS: VITE_ prefix, env block in workflow |
| Mic permission denied | User blocks microphone | Medium | Medium — mic mode unavailable | Graceful fallback to file upload only |
| Canvas OOM on mobile | Large canvas + heavy animation | Medium | High — tab crash | Cap canvas resolution, reduce particle count |
| Browser doesn't support Web Audio | Very old browser | Low | High — audio tool dead | Feature detection, show unsupported message |
| HashRouter breaks deep links | Manual URL manipulation | Low | Low — user sees tool grid | HashRouter is resilient by design |
| Firebase quota exceeded | 10K writes/day (presets P3) | Low (MVP) | Medium — saves fail | Batch writes, cache locally, upgrade to Blaze |

## CRITICAL FAILURE CHAIN

```
User visits /tools
  → clicks Audio Visualizer
  → AudioContext created on mount (WRONG — no gesture yet)
  → browser blocks it silently
  → AnalyserNode returns zeros
  → canvas renders flat line
  → user thinks tool is broken
  → leaves
```

**Fix**: AudioContext must be created inside the click handler of "Enable Mic" or "Upload File" button, not on component mount.

## SILENT FAILURES (hardest to debug)

| Silent Failure | Symptom | Detection |
|----------------|---------|-----------|
| AudioContext suspended | No error, just silence | Check `audioCtx.state === 'suspended'` |
| VITE_ env var missing | `import.meta.env.VITE_FIREBASE_X` is undefined | Console.log env on dev, check build log |
| Canvas not sized | 0x0 canvas, nothing renders | Check `canvas.width/height` after resize |
| AnalyserNode not connected | No frequency data | Verify `source.connect(analyser)` chain |

## RECOVERY STRATEGIES

| Failure | Recovery |
|---------|----------|
| AudioContext blocked | Show "Click to start" overlay, create on click |
| AudioContext suspended | `audioCtx.resume()` on visibilitychange |
| Env vars missing | Fallback config object with empty strings, tool works without Firebase |
| Mic denied | Show message, enable file upload as alternative |
| Canvas OOM | Reduce resolution to 50%, cap FPS to 30 |
