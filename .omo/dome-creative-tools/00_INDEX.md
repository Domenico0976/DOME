## STRONGEST CONSTRAINTS

1. **No server-side processing** — GitHub Pages is static-only
2. **Audio requires user gesture** — browser autoplay policy
3. **HashRouter only** — BrowserRouter breaks on Pages refresh
4. **VITE_ prefix for env vars** — Vite only exposes these to client
5. **1GB artifact limit** — ffmpeg.wasm must be dynamically imported
6. **Zero budget** — every feature must work on free tiers

## CRITICAL RISKS

1. **AudioContext silently blocked** → tool appears broken (fix: create on click)
2. **Vite base path wrong** → all assets 404 (fix: `base: '/tools/'`)
3. **Env vars empty** → Firebase init fails (fix: debug step in workflow)
4. **Site coexistence** → React app may conflict with existing DOME static site [OPEN-2]
