## CONNECTION MAP

### Deploy Flow

```
Domenico pushes to master
  → GitHub Actions webhook triggers
  → checkout@v4 (gets code)
  → setup-node@v4 (Node 20)
  → npm ci (install deps in tools-app/)
  → npm run build
    → Vite reads vite.config.js (base: '/tools/')
    → Vite exposes VITE_FIREBASE_* from env
    → Vite bundles React app → tools-app/dist/
    → Code-split: each tool is a separate chunk
  → upload-pages-artifact@v3 (from tools-app/dist/)
  → deploy-pages@v4
  → Live at dome-fusto.pages.dev/tools
```

### Runtime Flow

```
User visits dome-fusto.pages.dev/tools
  → GitHub Pages serves index.html (from dist/)
  → React mounts, HashRouter initializes
  → App.jsx renders ToolGrid
  → ToolGrid reads registry.js → shows tool cards
  → User clicks "Audio Visualizer"
  → React.lazy loads AudioVisualizer chunk
  → AudioVisualizer mounts inside ToolShell
  → User clicks "Enable Mic" or uploads file
    → useAudioAnalyser creates AudioContext (user gesture ✓)
    → AnalyserNode connected to source
    → useCanvasRenderer starts animation loop
    → requestAnimationFrame → getByteFrequencyData → draw
  → User adjusts sensitivity slider
  → Visual updates in real-time
  → User clicks "Export"
  → export.js: canvas.toBlob → download link
```

### Data Flow (P3 — Firebase presets)

```
Tool config change
  → debounce 500ms
  → Firebase Realtime Database ref('presets/{toolId}')
  → .set(config)
  → On reload: ref.on('value') → restore config
```

## CRITICAL CONNECTIONS

| Connection | From → To | Risk | Mitigation |
|------------|-----------|------|-----------|
| Vite build → Pages | dist/ → artifact | Wrong base path | Test build locally with `vite preview` |
| Env vars → Vite | Actions env → VITE_FIREBASE_* | Empty values | Debug step in workflow (echo length) |
| User gesture → AudioContext | Click event → AudioContext | Created too early | Create inside handler only |
| Registry → Tool component | React.lazy → dynamic import | Chunk 404 | Verify chunk paths after build |
| Canvas → Export | canvas.toBlob → download | CORS/tainted canvas | Ensure images loaded with crossOrigin |

## EXTERNAL DEPENDENCIES

| Dependency | Purpose | Risk | Alternative |
|------------|---------|------|------------|
| GitHub Pages | Hosting | Down time | None (free tier, high uptime) |
| GitHub Actions | CI/CD | Minute limit | Public repo = unlimited |
| Firebase | Data/Auth (P3) | Quota, outage | LocalStorage fallback (if not sandboxed) |
| npm registry | Package install | Package unavailable | Lock file (package-lock.json) |
| gstatic.com | Firebase SDK CDN | CDN down | Self-host SDK (not recommended for MVP) |
